# Architectural Decision Records

This folder tracks every significant decision made during the hackathon — what we chose, why, and what we rejected. Keeps the jury demo crisp and post-hackathon retrospectives honest.

## Format

Each ADR is a single markdown file named `ADR-NNNN-short-title.md`.

**Status options:** `proposed` | `accepted` | `superseded` | `deprecated`
