  How our current OpenTSLM pipeline uses it

  - Signal input: One six-hour window from a channel in 41–46 → normalization → time-series encoder → signal embeddings.
  - Text context: Channel name, raw mean, standard deviation and time since the most recent qualifying telecommand.
  - Output: A window-level classification: nominal or anomalous.
  - Evaluation: Compare the prediction with the ESA annotations; reference labels are excluded from the input.

  Suggested visual: Two branches — telemetry → signal embeddings and telecommands → timing context — merging at OpenTSLM, followed by the classification. Put ESA reference labels beside the evaluation stage.

  Speaker notes / implementation limits

  - Command context currently contains only a time interval, not command identity, meaning or a channel-specific relationship.
  - It considers commands with priority ≥ 2 within six hours before a reference point one hour into the window.
  - The current training target groups Anomaly and Rare Event together as anomalous. We should therefore not claim that this model already distinguishes faults from commanded rare events.

Problem + Data: Zielnutzer und konkretes Problem definieren, passende offene Daten beschaffen. Bei Bedarf eine agentische Pipeline nutzen, um Datensätze zu suchen, bewerten, auswählen und validieren. Ideal sind Datensätze mit Zeitreihen plus Text/Erklärungen; Textannotationen können ggf. auch mit LLMs erzeugt werden.
Connect: Einen TimeNet-Connector nutzen oder bauen, der Signale, Metadaten und Annotationen einbindet. Fragen, Labels bzw. Lernziele definieren. Wiederverwendbare Datenpipelines sind besonders wertvoll. TimeNet standardisiert Zeitreihendaten und Metadaten für das TSLM-Training.
Train + Evaluate: Ein TSLM trainieren oder fine-tunen und auf zurückgehaltenen Daten mit einer Baseline vergleichen. Dabei Datenlecks über Zeit, Personen oder Geräte hinweg vermeiden.
Demonstrate: Zeigen, woher die Daten stammen, welche realen Inputs und Modelloutputs verwendet wurden und wie das Ergebnis dem Zielnutzer hilft. Außerdem Evidenz und Grenzen des Ansatzes erklären.
